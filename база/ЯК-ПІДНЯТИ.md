# Як підняти базу

Postgres плюс PostgREST перед ним (рішення П-76 і П-92). Один раз.

Перевірено: Ubuntu 26.04, Godot 4.7.2. PostgREST у сховищах Ubuntu
**немає** — його беруть готовим бінарником із GitHub.

---

## 1. Postgres

```
sudo apt install -y postgresql
sudo -u postgres createdb myway
sudo -u postgres psql -d myway -f база/схема.sql
```

Схема створює `game.characters`, роль `game_api` (під нею ходить
PostgREST) і роль `game_anon` (її права й видно назовні). **Пароль у
`схема.sql` і в `postgrest.conf` замінити на свій** — там стоїть
`змінити-мене`.

## 2. PostgREST

```
curl -L -o /tmp/postgrest.tar.xz \
  https://github.com/PostgREST/postgrest/releases/latest/download/postgrest-ubuntu-aarch64.tar.xz
tar -xf /tmp/postgrest.tar.xz -C ~/.local/bin
postgrest база/postgrest.conf
```

Для звичайного комп'ютера архів називається `...-linux-static-x64.tar.xz`
— беріть той, що під вашу машину (`uname -m`).

## 3. Гра

```
./запуск-сервера.sh --база http://127.0.0.1:3000
./запуск.sh --run -- --персонаж Вовкодав
```

Сервер друкує, що знайшов:

```
[база] http://127.0.0.1:3000, зберігаю раз на 30 с
[база] Вовкодав повернувся: рівень 1, поваги 101
```

**Без `--база` гра працює як і раніше**, просто нічого не зберігає — і
каже про це першим же рядком: `[база] адреси немає — гра йде без
збереження`.

---

## Чим це перевірено без самої бази

`postgrest` тут не встановлено (потрібен пароль адміністратора), тому
клієнтську частину перевірено на **заглушці**, яка говорить тим самим
протоколом: `GET /characters?name=eq.Ім_я` і `POST /characters` із
заголовком `Prefer: resolution=merge-duplicates`.

Заміряно наскрізь, два запуски поспіль:

```
перший:  [база] http://127.0.0.1:3001, зберігаю раз на 30 с
         збережено: повага 101, досвід 22, речі {гроші 27, шкура 1},
                    скіли {вибух 1, промінь 1}, позиція x -0,37
другий:  [база] Вовкодав повернувся: рівень 1, поваги 101
         загинув -> [смерть] втратив 100 поваги, лишилось 1
         збережено знову: повага 1
```

Тобто гра справді зберігає, читає й накладає прочитане. Що лишається
перевірити на справжньому Postgres — тільки те, як він поводиться з
`jsonb` і чи вистачає прав ролі; сам протокол уже пройдено.
