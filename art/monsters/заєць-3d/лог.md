# Заєць — 3D-модель за референсом

Референс: `wiki/img/monstry/заєць.png`. Білдер: `tools/blender/make_hare.py`
(власний чотирилапий скелет, 10 кісток). Колір мобу: `mobs.json → #b08050`.
Кожна спроба — `спроба-NN.png` (Idle, три чверті) + тека `спроба-NN/` з усіма кадрами.

## Спроба 04 — новий шлях: сітка за референсом + хутро шарами (23.09.2026)
Слово замовника після 03: «дуже слабка початкова 3D модель, вона дуже примітивна і має
тільки формальні збіги з референсом, навіть хутро не промальовується, не бачу волосинок».
Кулі й циліндри стелі не пробивають — перейшли на image-to-3D.

Як зроблено:
1. `pixal3d-01` — Pixal3D (ComfyUI) прямо з референсу. Вийшло схоже, але в позі стрибка
   (лапи в повітрі), з травинками на лапах і блакиттю на хвості — для скелета не годиться.
2. FLUX Kontext (`flux1-kontext-dev-Q5_K_S.gguf`) переставив ТОГО САМОГО зайця в спокійну
   позу на сірому тлі: `поза-варіанти.png`, замовник обрав 4 (`поза-s44.png`).
3. `pixal3d-02` — Pixal3D з пози 4: чиста сітка з текстурою 4096.
4. `tools/blender/make_hare_scan.py`: розворот, лапи на нуль, зварити шви UV, спростити до
   ~20 тис. граней, текстури 2048, скелет під нову анатомію з тими ж іменами кісток і рухи з
   `make_hare.py`, ваги «теплом»; друга UV = маска голизни (очі, ніс, кігті, нутро вух).
5. Хутро в грі — `game/scripts/fur_shell.gdshader` (20 шарів `next_pass`), вмикається полем
   `вигляд.хутро` у `game/data/mobs.json`. Перевірка — `scenes/fur_look.tscn`.

| Пункт | Оцінка | Коментар |
|---|---|---|
| Колір хутра | ✓ | з референсу |
| Черево, груди | ✓ | світлі |
| Вуха | ✓ | довгі, темні кінчики, рожево-помаранчеве нутро |
| Очі | ✓ | великі темні з білим обідком |
| Ніс, писок | ✓ | |
| Вуса | ✓ | є в сітці (тонкі, частково з'їдені спрощенням) |
| Голова, тулуб, пропорції | ✓ | анатомія з референсу, а не з примітивів |
| Задні / передні ноги | ✓ | довгі задні, кігті |
| Хвіст | ✓ | білий пухнастий |
| Ворс | ✓ | видно волосини по силуету й на спині; кільця шарів лише зовсім зблизька |
| Поза | ~ | не стрибок, як на референсі, а спокійна стійка — навмисно, під скелет |

Проба `own_models.gd`: ✓ Attack/Death/Idle/Walk, ✓ зріст, ✓ морда вперед.
Картинка у вікі — знімок із Godot з хутром → `wiki/img/monstry/заєць-модель.png`.
Процедурний заєць (спроби 01–03, `make_hare.py`) лишився як був — його функції беруть вовк і ведмідь.
