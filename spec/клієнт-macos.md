# Клієнт MyWay на Mac — інструкція гравцеві

26.11.2026. Клієнт лише показує гру й передає твої наміри. Персонаж, бій,
речі, вхід і пароль — усе на сервері (P1), тож без запущеного сервера
клієнт нічого не покаже, крім стартової сторінки.

## Гравцеві: п'ять кроків

1. **Завантаж** `MyWay-macos-<дата>-<коміт>.zip` (дає власник сервера) і
   двічі клацни по ньому: Finder розпакує поруч `MyWay.app`. Перенеси її
   в «Програми» (Applications) або лиши, де є.

2. **Перший запуск — повз Gatekeeper.** Застосунок не підписаний Apple
   (лише ad-hoc підписом), тому подвійне клацання скаже «не вдається
   перевірити розробника». Один із двох способів, лише раз:
   - **ПКМ (або Control+клік) по MyWay.app → «Відкрити» → «Відкрити».**
     На macOS 15 і новіших цієї кнопки може не бути: тоді спробуй відкрити
     раз, потім «Системні параметри → Приватність і безпека» → внизу
     «MyWay заблоковано» → **«Усе одно відкрити»**.
   - Або в Терміналі (шлях — куди поклав застосунок):
     ```
     xattr -dr com.apple.quarantine /Applications/MyWay.app
     ```
   Якщо macOS пише «MyWay пошкоджено, його слід викинути в кошик», — це
   те саме карантинне позначення: допомагає саме `xattr` вище.

3. **IP сервера.** На стартовій сторінці одне поле — **«IP сервера»**.
   Введи адресу, яку дав власник, наприклад `192.168.1.48`. Якщо сервер на
   нетиповому порту — з двокрапкою: `192.168.1.48:24601`. Типовий порт
   24565 писати не треба. Адреса запам'ятовується: наступного разу вона
   вже стоїть у полі.

4. **«Підключитися».** За секунду-дві з'явиться екран входу. Якщо сервер
   не відповів за 10 с, клієнт повернеться на стартову сторінку й скаже
   червоним, що сталось (невірний IP, сервер вимкнений, брандмауер не
   пускає). Ця сама сторінка з причиною з'явиться, якщо зв'язок обірвався
   посеред гри.

5. **Вхід і персонаж.**
   - Перший раз: ім'я акаунта, пароль (не коротший за 6 знаків) →
     **«Завести акаунт»**. Далі — **«Увійти»**.
   - Немає персонажів — введи ім'я, обери расу, стать, зовнішність →
     **«Створити»**.
   - Натисни на персонажа в переліку — і ти у світі.

Унизу ліворуч на стартовій сторінці й на екрані входу — **версія**
(«коміт · дата»). Скаржишся на ваду — назви її.

Збереження клієнта (остання адреса) лежить у
`~/Library/Application Support/Godot/app_userdata/MyWay/`.

Mac: Apple Silicon (M1 і новіші) і Intel — один і той самий застосунок
(Universal). Потрібна macOS 11 на Apple Silicon або 10.13 на Intel;
малює через Vulkan поверх Metal (MoltenVK, уже всередині застосунку).

## Власникові: що на боці сервера

**Сервер.** Той самий, що й завжди, **обов'язково з базою** — без бази
сервер пускає без входу, і в клієнта не буде екрана входу й персонажів:

```
./run-db.sh                                   # PostgREST на 127.0.0.1:3000
./run-server.sh --світ2 --база http://127.0.0.1:3000
```

Або стартова сторінка `./play.sh`: «Підняти базу», «Підняти сервер».

**Порт:** UDP **24565** (ENet; TCP не потрібен). Сервер слухає на всіх
адресах машини — `ss -ulpn | grep 24565` показує `*:24565`. Інший порт —
`./run-server.sh --порт 24601 …`, і гравець тоді вводить `IP:24601`.
База (PostgREST 3000, Postgres 5432) назовні **не потрібна** й не має
бути відкрита: до неї ходить лише сервер гри, на тій самій машині.

**Брандмауер.** На цьому ПК увімкнено `ufw` із політикою вхідних DROP
(`/etc/default/ufw`), тож гравця з іншої машини він, найімовірніше, не
пустить. Правила самі по собі прочитати без `sudo` не вдалося. Пропозиція —
відкрити лише UDP-порт і лише для домашньої мережі:

```
sudo ufw status numbered            # чи вже є правило на 24565
sudo ufw allow from 192.168.1.0/24 to any port 24565 proto udp comment 'MyWay'
```

Перевірка з самого ПК на його ж LAN-адресу брандмауер **не проходить**
(пакет іде через `lo`), тож справжня перевірка — лише з іншої машини.

**IP сервера:**

```
ip -4 addr show | grep 'inet 192.168'   # на 26.11.2026: 192.168.1.48 (wlp6s0)
hostname -I
```

Адреса з DHCP може змінитися — краще закріпити її за ПК у роутері.

**Версії мають збігатися.** Клієнт і сервер — з одного коміту: виклики
між ними не мають номера версії, і різні збірки ламаються мовчки (не
той перелік аргументів RPC). Версію клієнта видно на екрані входу,
сервера — `git log -1` там, звідки його запущено.

**Пароль летить мережею відкритим** (ENet без шифрування, П-114). Для
домашньої мережі це прийнятно, для інтернету — ні.

## Як зібрати клієнт

```
tools/zibraty.sh              # усі платформи, для яких є шаблони
tools/zibraty_macos.sh        # лише macOS
```

Виходить `build/myway-<дата>-<коміт>/`: `macos/MyWay.app`,
`linux/MyWay.x86_64` + `MyWay.pck`, `windows/MyWay.exe` + `MyWay.pck`,
`versiia.json`, і поруч zip кожної платформи для гравця. Рушій і дані
(`.pck`) — окремими файлами, щоб апдейтер перекачував лише змінене.
Godot — лише `--headless`, відеокарта не потрібна.

Шаблони експорту мають лежати в
`~/.local/share/godot/export_templates/4.7.2.stable/`. На 26.11.2026 їх
там **немає**: набір розпаковано в `…/export_templates/templates/` (без
теки версії), і `macos.zip` у ньому **обрізаний** (30 МБ, `unzip -t` не
проходить), а шаблонів Windows немає взагалі. Що зробити:

```
# завантажити (≈1 ГБ):
#   https://github.com/godotengine/godot/releases/download/4.7.2-stable/Godot_v4.7.2-stable_export_templates.tpz
cd ~/.local/share/godot/export_templates
unzip -o ~/Завантаження/Godot_v4.7.2-stable_export_templates.tpz   # дасть templates/
mv templates 4.7.2.stable
unzip -tq 4.7.2.stable/macos.zip && echo macos.zip цілий
```

Доти скрипт можна ганяти з наявною текою для Linux:
`TEMPLATES_DIR=~/.local/share/godot/export_templates/templates tools/zibraty.sh linux`.

## Для апдейтера

- Клієнт запускається з адресою: `MyWay -- --host 192.168.1.48[:порт]`
  (macOS: `MyWay.app/Contents/MacOS/MyWay -- --host …`). У зібраному
  клієнті він тоді **підключається сам**, раз; не вдалось — лишається на
  сторінці з причиною й адресою в полі.
- Версія: `MyWay -- --version` друкує «коміт · дата» і виходить. **Саме
  після `--`**: голий `--version` перехоплює рушій і друкує свою версію
  («4.7.2.stable…»). Те саме з `--host`: без `--` гра його не бачить.
  Та сама версія лежить у `versiia.json` поруч зі збіркою.
- Дані гри — `MyWay.pck` (на Mac — `MyWay.app/Contents/Resources/MyWay.pck`),
  рушій — окремо; міняється здебільшого лише `.pck`. Після заміни
  файлів у `.app` ad-hoc підпис бандла стає недійсним: на Apple Silicon
  це може зупинити запуск — апдейтер має або міняти бандл цілком, або
  перепідписувати `codesign --force --deep -s - MyWay.app` (на Mac).
