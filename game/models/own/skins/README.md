# Скіни на пробу

Тека для перевірки скінів у переглядачі моделей (`./run.sh --моделі`).

    models/own/skins/<назва моделі без розширення>/<будь-яка назва>.png|jpg

Напр. `models/own/skins/elf-s808-mixamo/засмага.png` — у переглядачі під
«Скін» з'явиться кнопка «скін: засмага.png», що кладе цю картинку кольором
на всі поверхні моделі. Картинка має бути в тій самій розгортці (UV), що й
рідна текстура моделі — тобто перемальована з неї. Після нових файлів —
`godot --headless --path game --import`, інакше Godot їх не бачить.
