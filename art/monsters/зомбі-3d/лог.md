# Зомбі — 3D модель, шлях А (image-to-3D), той самий підхід, що імп/паглін (П-247)

Заміна процедурного рескіну людини (`humanoids.py`,
`res://models/own/humanoids/зомбі.gltf`) на модель за референсом, свій
скелет.

## Крок 1 — чекліст референсу (`wiki/img/monstry/зомбі.png`)

- **Голова:** обвисле обличчя, шкіра синьо-зелена; очі червоні, каламутні
  (за описом), рот роззявлений, зуби видно; лисий череп.
- **Тулуб:** дуже роздуте тіло (бочкоподібний живіт), синьо-зелена шкіра;
  на грудях/животі рана з кров'ю; м'язисті плечі й руки контрастують із
  роздутим животом.
- **Кінцівки:** дві руки — товсті, висять по боках, розведені, пальці
  скарлючені; дві ноги — товсті, одна нога не згинається (за описом) —
  на арті обидві прямі, не видно різниці; босі стопи.
- **Хвіст:** немає.
- **Амуніція:** рештки штанів/спідниці, обірвані знизу, закривавлені.
- **Зброя:** немає (б'є голими руками).
- **Постать:** широко розставлені ноги, руки розведені в боки, злегка
  нахилений уперед, горблячись.
- **Поза на арті:** майже строго анфас, звичайна перспектива, повний
  зріст у кадрі з запасом — камера не близько й не низько. **Крок А3
  пропущено** (як вовк 23.09.2026): руки розведені в боки й добре
  відокремлені від тіла — вигідна поза для Pixal3D без Kontext.

## Крок А4–А6 — сітка й білдер (`tools/blender/make_zombie_scan.py`)

Сітка `pixal3d-01.glb` прямо з референсу (без Kontext) — анатомія за
чеклістом, морда на −Y без повороту. Той самий скелет на 7 кісток
(без хвоста — бестіарій каже «немає»), координати з Z-гістограми й
центроїдів (`landmarks_zombie.py`). Тепло спрацювало нормально (39
вершин запасним варіантом із 8587).

**Спроба 01:**
| Пункт | Оцінка | Коментар |
|---|---|---|
| Прив'язка | ✓ | тепло спрацювало |
| Idle | ✓ | силует ідентичний референсу |
| Walk | ✓ | |
| Attack | ~→✓ | перші два прогони підняття рук (±70°) заводили кулак повз голову — оптична ілюзія «другої голови»; **ліва й права кістка руки мають різний природний roll** (виміряні асиметричні позиції) — той самий кут давав різний результат; зменшено до ±35°/−25° й підібрано окремо для кожної руки |
| Death | ✓ | складається вперед, як в описі |
| Проба `own_models.gd` | ✓ | рухи: Attack, Death, Idle, Walk; зріст і морда — ✓ |

**Нове спостереження для наступних гуманоїдів:** ліва й права кістки
кінцівки, побудовані з окремо виміряних (не дзеркальних) координат,
можуть мати різний roll і потребувати різних кутів повороту для
однакового візуального руху — перевіряти обидві сторони окремо, не
припускати симетрію.
